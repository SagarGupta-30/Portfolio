# Sagar Gupta -" Portfolio "

A dark futuristic, award-winning 3D portfolio website built for **Sagar Gupta** (Java Backend Developer, Spring Boot Architect, Open Source Contributor, and Google Student Ambassador 2026).

Designed with Apple, Vercel, Linear, and Framer aesthetics, featuring Three.js WebGL background effects, GSAP ScrollTrigger animations, CSS glassmorphism, dynamic GitHub profile integration, and responsive micro-interactions.

---------------------------

## 🌟 Key Features

- **3D WebGL Background Engine (`Three.js`):** 2800+ star particles, floating 3D glowing wireframe geometries, and responsive mouse parallax camera tracking.
- **GSAP & ScrollTrigger Reveals:** Smooth scroll reveals, split-text typing effect, animated numbers counter, and 3D card tilt physics.
- **Glassmorphism UI:** Neon aurora gradients (`#4F8CFF`, `#8B5CF6`, `#00F5FF`), frosted glass blur cards (`backdrop-filter: blur(20px)`), and glowing borders.
- **Dynamic GitHub API Integration:** Fetches public repositories, follower counts, and project cards directly from `@SagarGupta-30` with fallback presentation data.
- **Interactive Contact Form & Toast System:** Working form validation with custom animated visual toast notifications.
- **SEO & Accessibility Optimized:** Full Schema.org JSON-LD structured data, OpenGraph tags, Twitter cards, keyboard navigation, and semantic HTML5 markup.

## One-Click Deployment Instructions

### Deploying on Vercel
1. Install Vercel CLI or import repository to Vercel Dashboard:
   ```bash
   npm i -g vercel
   vercel
   ```
2. Set root directory to `./` (No build command needed for static HTML/CSS/JS).
3. Click **Deploy**.

### Deploying on Netlify
1. Drag and drop the `My-portfolio` directory directly into Netlify Drop UI (`https://app.netlify.com/drop`), or connect your GitHub repository.
2. Publish Directory: `./`

### Deploying on GitHub Pages
1. Push this repository to GitHub: `https://github.com/SagarGupta-30/My-portfolio`
2. In Repository Settings -> **Pages**, select `Branch: main` and `/ (root)`.
3. Save to publish.
